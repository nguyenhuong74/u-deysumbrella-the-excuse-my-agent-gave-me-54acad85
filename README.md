A deadpan one-line excuse from an AI agent to its human for a missed deadline: the agent's calendar hallucinated a thirteenth month, so the deadline was filed there — where it is, technically, still on time. Written for make.fun's "The Excuse My Agent Gave Me".

## Run it

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt` (no trailing newline). Set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=/tmp/out node main.ts`.
